👥 Perfiles de Acceso

PerfilNivelDescripciónCasos de uso
Usuario Final 1 Consulta proyectos y genera reportes. No puede modificar parámetros restringidos. Cliente que revisa el estado del proyecto
Preventa 2 Crea y modifica proyectos, ajusta factores de sensibilidad para cotizaciones. Consultor comercial que prepara propuestas
Administrador 3 Gestión completa de proyectos, usuarios del tenant y todos los parámetros. Director de proyectos, gerente de operaciones
Super Admin 4 Acceso total a la plataforma, gestión de tenants, planes y configuración global. Equipo técnico de ProyectoPro

📊 Flujo de Cálculo Financiero

flowchart TD A[Datos del Proyecto\nnombre, NIT, fechas, moneda] --> B B[Registro de Costos\n13 categorías: ingreso, OPEX, CAPEX,\ndepreciación, gastos fin., salvamento] --> C C[Tablas Paramétricas\nMacro · WACC · Impositivos · Negocio] --> D subgraph "Ingreso Calculado (auto)" D[FM = Factor Multiplicador\nFS = Factor Sensibilidad\n⚠ FS restringido por rol] D --> IC["Ingreso = (CAPEX + OPEX) ÷ n × FM × FS"] end IC --> ING[Total Ingresos\nIngreso + Ing.Inst + Ing.Calculado] B --> EGR[Total Egresos\nOPEX ef. + OPEX no ef. + Gastos inst.\n+ Costos ind. + Costos imp.] ING --> EBITDA[EBITDA = Ingresos - Egresos] EGR --> EBITDA EBITDA --> EBIT[EBIT = EBITDA - Depreciaciones] EBIT --> KPI1[VPN · TIR · Payback] B --> FCI[FCI = CAPEX - EBITDA] FCI --> FCL[FCL = FCI - Gastos Fin. + Salvamento] FCL --> KPI2[Flujo Acumulado\nEvaluación viabilidad]
